EViewsCompat: EViews-style estimation and functions for gretl

GUI: Model > Linear models > EViews-style equation (LS)
  Type the equation exactly as in EViews' "Equation Estimation" box, e.g.
      dlog(lrm) c dlog(lry) lrm(-1) ibo ide
  and select (at least) the series the equation uses. The result window
  shows the EViews-style table; its graph button draws Actual/Fitted/Residual.
  Save the result as an icon to keep it in the session (like an EViews
  workfile object).

Note: hansl names are case-sensitive, so type series names as they appear
in gretl. EViews keywords (c, log, d, dlog, the @-functions) are not.

Functions (CLI / console). "dataset" means: all series in the dataset.

  ev_ls(spec, dataset [, cov] [, quiet])  -> bundle
      Least squares. spec in EViews syntax. cov: "ordinary" (default),
      "white" or "hac". Prints the EViews-style table unless quiet = 1.
      Supported terms: c, x, x(-k), log(x), d(x), dlog(x), exp(), abs(),
      sqr(), any gretl expression, @trend, @seas(k), @pch, @pc,
      @pchy, @pcy, @movav(x,n), @movsum(x,n), @cumsum,
      @mean, @stdev.
      Bundle members: coeff, stderr, tstat, pval, vcv, rsq, adjrsq, sigma,
      ssr, lnl, dw, aic, sc, hq, F, Fp, T, k, uhat, yhat, y, X, sample.
      aic/sc/hq use EViews' per-observation scaling (gretl value / T).

  ev_wald(eq, "c(2)=0, c(3)=c(4)")      -> bundle (F, Fp, chi2, chi2p)
      Linear coefficient restrictions in EViews c(i) notation.

  ev_diag(eq [, lags])                  -> bundle
      Jarque-Bera, Breusch-Godfrey LM (default 2 lags), White test with
      cross terms; F and Obs*R-squared versions as in EViews.

  ev_freeze(eq, "file.csv")             save table (.txt .csv .tex .html)
      Relative names are written in the gretl working directory.

  ev_print(&eq), ev_plot(&eq)           print table / Actual-Fitted-Residual

  ev_gen("expr", dataset)               EViews expression -> series
  ev_trend(), ev_seas(k), ev_pch(x), ev_pc(x), ev_pchy(x), ev_pcy(x),
  ev_movav(x,n), ev_movsum(x,n), ev_mean(x), ev_stdev(x) (n-1),
  ev_var(x) (population, n), ev_obs(x), ev_elem(x, "1990:1")

Forecasts (eq.forecast). The forecast sample is the current sample.

  ev_forecast(eq, dataset [, dynamic=1] [, quiet])   -> bundle
      Static (0) or dynamic (1). Dynamic forecasts replace lags of a plain
      dependent variable, y(-k), by earlier forecasts. Bundle: yf, se,
      actual, rmse, mae, mape, theil, bias_prop, var_prop, cov_prop.
  series f = ev_fcast_series(fc)     series s = ev_fcast_se(fc)
  ev_fplot(&fc [, "file.png"])       forecast with +/- 2 S.E. and actual

VAR objects (var v.ls 1 2 y1 y2 @ c x)

  ev_varest("1 2 y1 y2 @ c x", dataset [, quiet] [, "names"])  -> bundle
      Lag pairs (1 2 = lags 1 to 2), endogenous variables, then exogenous
      after the at-sign; c = constant (included by default when there is no
      exogenous part). Use series names so lags can use pre-sample data;
      "names" gives display names, e.g. "dlog(cons) dlog(gdp)".
  ev_varprint(&v)               EViews-style estimates: coef, (s.e.), [t]
  ev_vargranger(v)              Granger causality / block exogeneity Wald
  ev_varirf(v, 10)              impulse responses (Cholesky)
  ev_varirfplot(v, 10 [, "file.png"])   grid of response graphs
  ev_vardecomp(v, 10)           variance decomposition (percent)
  ev_varlaglen(v, dataset, 8)   lag length criteria
  series r = ev_varresid(v, 1)  residuals of equation 1

Explicit equations, ARMA terms (ev_ls dispatches automatically)

  ev_ls("y = c(1) + c(2)*x^c(3)", dataset)    nonlinear least squares
  ev_ls("y c x ar(1) ar(4) ma(1)", dataset)    regression with ARMA errors (ML)
      ARMA output shows SIGMASQ and the inverted AR/MA roots. Forecasts of
      either kind use the same ev_forecast call.

Forecasts of transformed dependents

  ev_forecast(eq, dataset, 1, 0, 1)   dynamic forecast reported in levels:
      for log(Y), d(Y), dlog(Y) the forecast of Y is built step by step and
      every regressor that uses Y is recomputed. ev_fcast_series(fc, 1) and
      ev_fcast_se(fc, 1) give the level forecast and its S.E. Dynamic S.E.
      follow the lags of the dependent variable (innovation uncertainty).

Systems (system sys1 / sys1.sur)

  ev_system(deps, xspecs, cnums, dataset, "sur" [, "z1 z2"])
      deps: array of dependent variables; xspecs: regressors per equation
      ("c x1 x2"); cnums: coefficient numbers per equation ("1 2 3"); the same
      number in two equations shares the coefficient. Methods ls, sur, tsls,
      3sls; instruments get a constant added. ev_wald works with c(i).

VEC models (var v.ec(c, 1) 1 2 y1 y2)

  ev_vecm("1 2 y1 y2 [@ x]", dataset, "c", 1)   trend case a-e, rank
  ev_coint("y1 y2", dataset, "c", 4)            Johansen test
      The VAR views (ev_varirf, ev_varirfplot, ev_vardecomp) work on VEC results.

More system estimators
  ev_system(..., "wls" | "wtsls" | "gmm", "z1 z2")   weighted LS, weighted TSLS,
      two-step GMM with White weighting (J-statistic reported)
  FIML: estimate with gretl's system command (method=fiml), then
      ev_sysfrom("fiml", $coeff, $vcv, $uhat, $yhat, pos, cnums, kk, deps, eqtext, $t1, $lnl)
      gives the EViews-style result (the translator and evqt do this for you)

Structural VAR (v.svar)
  ev_svar(&v, A, B)   short-run A e = B u: in A and B, numbers are fixed and NA
                      entries are estimated (ML); LR test of over-identification
  ev_svar_lr(&v)      long-run (Blanchard-Quah) restrictions
      Afterwards ev_varirf, ev_varirfplot and ev_vardecomp use the structural shocks.

Model objects (model m / m.merge eq / m.append identity / m.solve)
  ev_modelsolve(bundles eqs, strings identities, dataset [, dynamic=1])
      Solves least-squares and explicit equations plus identities period by period
      (Newton). ev_modelseries(m, k) is the solution of endogenous variable k.

Nonlinear systems and HAC GMM
  ev_nlsystem(eqs, dataset, "ls|wls|sur|tsls|3sls|gmm" [, "z1 z2"] [, quiet] [, haclag])
      equations written as y = f(x, c(i)); shared c(i) across equations;
      Levenberg-Marquardt with numerical derivatives
  ev_system(..., "gmm", "z1 z2", quiet, eqtext, haclag)   haclag 0 = Newey-West
      automatic lag, k = Bartlett lag k, -1 (default) = White

Text-form structural restrictions (EViews @e / @u / @lr) are turned into A/B
patterns or a long-run ordering by the translator and evqt; in hansl call
ev_svar(&v, A, B) or ev_svar_lr(&v, 0, {order}).

Model options: ev_modelsolve(eqs, identities, dataset, dynamic, quiet, opts)
  opts = _(overrides = defarray("x"), suffix = "_1", addfactors = 1, reps = 100, seed = 1)
  overrides use series x_1 in place of x; add factors are series <variable>_a
  (ev_eqres(eq, dataset) makes an equation fit exactly); reps > 0 runs a
  stochastic simulation: ev_modelseries(m, k, "mean") and (m, k, "sd").

ARCH models (needs the gig package, installed with gretl)
  ev_garch("y c x", dataset, "garch|tarch|egarch", narch, ngarch [, quiet]
           [, "sd|var|log" (ARCH-M term)] [, nthr (threshold order, -1 = default)])  -> bundle
      EViews equation.arch(narch, ngarch[, t|e]). Coefficients are in EViews order and
      parameterisation: mean equation, then C(.) of the variance equation
      GARCH  : h = w + a e(-1)^2 + b h(-1)
      TARCH  : h = w + a e(-1)^2 + g e(-1)^2 (e(-1) < 0) + b h(-1)
      EGARCH : log h = w + a |z(-1)| + g z(-1) + b log h(-1),  z = e/sqrt(h)
      b.failed = 1 when the estimation does not converge (a warning is printed).
  ev_garchprint(&b)            EViews-style output with the variance equation
  ev_garchseries(b [, "h"|"resid"])   conditional variance or residual series

Panel pages
  setobs id time --panel-vars        (EViews pagestruct id @date(time))
  adf k x --c                        on a panel prints the Im-Pesaran-Shin test
  ev_unstack(x)   -> T x N matrix, one column per cross-section unit
  ev_panelids(id) -> the identifier of each unit, in panel order

Panel least squares (EViews ls on a panel page)
  ev_panel("y c x", dataset [, "none|fixed|random"] [, period_fe] [, quiet])  -> bundle
      ls(cx=f) / ls(cx=r) / ls(per=f); only the regressors are reported, as in EViews
  ev_panelprint(&b); ev_resid(b) and ev_fit(b) give residual and fitted series

pagestack helpers
  ev_stackids("x_?", dataset)   -> strings: the identifiers ? of matching series
  ev_stack("x_?", dataset [, ids]) -> T x N matrix, one column per identifier
